# 🌙 Dark Mode Toggle Website

A basic practice website built with HTML, CSS, and JavaScript that implements a Light/Dark mode toggle using localStorage.

## Features
- Theme toggle button  
- Saves user preference  
- Uses CSS variables  
- Beginner-friendly JavaScript  

## Tech Stack
- HTML  
- CSS  
- JavaScript  

## How to Run
Open `index.html` in your browser.
